# Contributing

> This repository provides documentation and integration examples for the FreeChemDraw hosted MCP service. The server implementation is privately maintained.

Contributions cover documentation corrections and translations, safe integration
examples, synthetic bug reports and feature suggestions. The server source is
privately maintained and is not included in external pull requests.

Use [Issues](https://github.com/chemaiatlas/freechemdraw-mcp/issues) for proposals
and [pull requests](https://github.com/chemaiatlas/freechemdraw-mcp/pulls) for document
or example changes. Explain the change, check links and JSON, and keep all three
README versions consistent. Use public ethanol (`CCO`) examples and preserve the
actual tool names and argument fields in [tools](docs/tools.md).

Do not include credentials, user structures, real editor-link URLs, production
logs or server implementation code. Do not claim support or certification without
evidence. Security reports follow [SECURITY.md](SECURITY.md), not public issues.
