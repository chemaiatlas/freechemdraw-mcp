# FreeChemDraw MCP Server

**Chemical Structure Tools for AI Agents**

FreeChemDraw MCP Server brings chemical structure processing capabilities to AI-powered workflows through the Model Context Protocol (MCP).

Convert molecular structures, calculate molecular properties, and generate chemical structure visualizations directly from compatible AI clients.

Built for researchers, chemists, developers, educators, and AI-powered chemistry applications.

## Features

- **Chemical Structure Conversion** — Process and convert supported molecular structure formats.
- **Molecular Property Calculation** — Calculate molecular properties such as molecular weight, LogP, and TPSA.
- **Structure Visualization** — Generate 2D molecular structure images.
- **MCP Integration** — Connect compatible AI agents to chemical tools.
- **REST API** — Integrate chemical processing capabilities into applications.

Available tools and supported formats may vary by deployment configuration.

## Get Started

**Hosted MCP Endpoint**

`https://ai.freechemdraw.com/mcp`
