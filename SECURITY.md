# Security reporting

> This repository provides documentation and integration examples for the FreeChemDraw hosted MCP service. The server implementation is privately maintained.

Report vulnerabilities privately. When GitHub private vulnerability reporting is
enabled, use the repository's Security tab. Otherwise use the official
[contact entry](https://ai.freechemdraw.com/contact) to obtain a private channel;
it points to the operator's configured support contact or the FreeChemDraw site.
If a private channel is unavailable, request one without disclosing vulnerability
details. Do not submit exploit details in a public issue.

Never send passwords, access credentials, cookies, real editor-link URLs or private
chemical structures. Use a synthetic ethanol reproduction and non-secret request
identifiers where sufficient. Provide impact and reproduction details only through
the confirmed private channel. No response-time SLA or bounty program is promised.

This repository contains documentation and integration examples. Do not attach
private server code to reports or imply that this repository grants access to it.
